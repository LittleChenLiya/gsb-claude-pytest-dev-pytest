Added the ``--stable-manifest=PATH`` option (builtin ``stablemanifest`` plugin): after collection, pytest writes a JSON manifest with a stable identity for every parametrized test -- built from the relative source path, the original test name, parameter names and explicit IDs -- and exits without running test bodies. Parameters without an explicit ID whose values cannot be stably encoded are reported as ``unstable`` (never silently hashed), and duplicate identities are reported as conflicts naming both nodeids. The manifest is intended for cross-machine comparison of test selection.
